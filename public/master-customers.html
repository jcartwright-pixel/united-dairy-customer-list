Upload the master address list

What an upload changes
  • The file needs DC, Chain, Account, Customer and the street, city, state and ZIP. Status (Active or Inactive), Latitude, Longitude, Phone, Contact, Group, Match status, Matched address and Coordinate source are read when they are there.
  • Changes each customer's name, chain, distribution center and address, and the GPS, phone, contact, group and status the file has. Adds a customer the list does not have yet (with no route).
  • Keeps routes, run and load order, notes, keys, anything the file leaves blank, and a checked ship-to address. A PO box, mailbox or c/o never replaces a street.
  • Removes a customer from an earlier master list that this one no longer has, only if it is on no route and the file is the whole list.
  • A sheet of checked ship-to addresses (Account, Street, City, State, Zip) goes in with the same button.
